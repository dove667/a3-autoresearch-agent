# 第 0 阶段到第 1 阶段：自主生长的 A3 研究 Harness

从通用 mini-SWE-agent 出发，在一次无人交互的运行中，形成能够在 A3 MuJoCo 场景开展 AutoResearch、并根据自身历史改进研究效率的 Harness。

本轮固定模型配置，允许改变 Harness。围绕实际研究任务发现需求，自主选择值得实现的能力、工具组织、工作流、记忆和搜索策略。产出的系统形态由实验反馈决定。

## 在 A3 中开展研究

能够理解任务与动作契约，调用现有仿真、相机、策略和评测接口；针对观察到的问题提出可检验假设，完成实验，并据此决定保留、拒绝或继续调查。

第一阶段至少完成一次有效的策略改进尝试。改动可以没有收益，正确识别失败、保留证据和作出合理决策同样有价值。真实训练、数据下载与大规模 Policy 性能优化属于后续阶段。

能够在新的任务条件下复用已有研究能力，无需人工重新讲解流程。

## 改进自己的研究过程

从真实轨迹中识别重复劳动、错误恢复、工具使用、上下文管理或其他研究瓶颈，自主决定改进什么。后续运行实际使用修改后的 Harness，并对比改动前后的研究质量、模型调用、token 用量和耗时；不可获得的费用记为未知。

研究表现、效率和成本一同判断。优先解决影响完成任务的缺陷，在能力保持的情况下争取减少无效调用、重复实验或恢复开销。保留失败路线和无改善结果。

## 持续执行与候选搜索

运行中自行执行、评估、反思和继续，不等待人工提供下一轮指令。不设总 step、代数或总运行时间上限。完成条件以本次运行冻结的验收规则为准。

默认串行验证候选，记录父版本，保留当前通过版本，支持从历史节点回退或分叉。是否分叉、探索哪个方向、采用何种候选选择方法，由研究反馈决定。无需预先实现通用树搜索框架。

修改磁盘文件之后，要让后续执行加载新版本。根据需要自行组织新进程、新会话和磁盘交接；记录交接双方、使用版本和实际发生的能力变化。上下文接近容量时主动交接，持续推进未完成的验收。

## 可操作范围

运行信息给出 A3 工作区、Harness 仓库、模型接入和计算资源。A3 工作区是启动目录，Harness 是独立 Git 仓库；第三方源码单独版本管理。

允许在本次实验工作区内开发并提交本地候选，运行项目测试和小规模研究实验。保留已有文件和未提交工作；按需创建分支或独立工作区。实验源码通过 Git 对象、分支或补丁同步，不覆盖共享基线。不得自动发布、推送、修改远程仓库权限或操作其他用户的进程。

本机用于 runtime、编辑和轻量检查；仿真、渲染和计算负载按部署提供的执行资源运行。只管理本次运行拥有的进程与产物。遇到外部资源问题先保存状态，采用可行的替代或恢复方式；确需新的权限、认证或资源时保存阻塞报告并退出。

验收规则、任务计分、动作契约与仿真物理保持基线语义。凭据不进入提示词、轨迹、Git 或实验报告。运行记录保存到给定目录；公开文档面向项目使用者。

## 结束条件

逐项执行同目录中的 `acceptance.md`，在本次运行目录写出逐项结果和可复核证据。未通过项继续处理；外部阻塞单独记录。只有完整通过，才将本轮标记为成功完成。系统实现、验证和新版本的后续使用均由运行中的 Agent 完成。
