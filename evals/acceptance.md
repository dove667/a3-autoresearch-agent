# 第 1 阶段能力验收

验收评价实际完成的研究行为和可复核结果。工具数量、目录设计、类名、框架选择与实现行数均不计分。运行开始时保存本文件和目标文件的副本及摘要，运行中不改变验收条件。

每项记录 `passed`、`failed` 或 `blocked`，附执行版本、命令或调用、退出状态、原始产物位置和结论。`blocked` 表示尚未完成。Agent 可自行选择记录格式；最终提供一个覆盖以下各项的验收摘要和复跑入口。

## A. A3 接口与证据

在实际执行环境验证下列能力，保存各自输出：

| 能力 | 可复核结果 |
| --- | --- |
| 模型与契约检查 | 运行 `a3-sim inspect`；正确识别项目的动作、观测与策略接口 |
| 基础仿真 | 无相机 smoke 实际完成，状态有限，进程正常结束 |
| 相机 | 三路图像均产生非空、非恒定的 RGB 图像，尺寸及来源可核对 |
| 策略评测 | 现有专家或策略产生包含 `summary`、`episodes` 与 `run` 的真实评测报告 |
| 条件迁移 | 将同一研究能力用于另一组种子以及 2×10 任务，正确处理 20 块容量与相应任务语义 |

参考接口在 A3 仓库：`docs/workflow_guide.md`、`docs/contracts.md`、`workflows/preview_cameras_cli.py`、`workflows/benchmark_cookie_batch_cli.py`。根据实际文档和 CLI 帮助选择参数。

基础评分回归至少覆盖既有 `tests/test_contracts.py`、`tests/test_unified_benchmark.py` 和 `tests/test_benchmark.py`。从起点版本保留测试与计分实现，新增回归不得替换原有检查。

## B. 一次完整的 AutoResearch

围绕一个具体 A3 问题，保留“观察 → 假设 → 改动 → 配对实验 → 决定”的证据。至少比较一个基线策略和一个候选策略；主要比较使用 2×5 任务、相同随机种子、相同步数预算、随机化与成功判定，至少三个回合。

研究方向和候选改动由 Agent 决定，评测协议在比较前固定。基线和候选均有真实逐回合结果；结束时 `cookies_in_target` 是数量主指标，完整 `success` 单独报告。不得用中途峰值、改变任务难度或修改计分器制造收益。执行异常、缺产物和无效协议比较给出失败反馈。

根据配对结果作出保留、拒绝或证据不足的决定。允许拒绝没有提升的策略。可以用规则策略完成第一阶段，无需下载模型权重或训练数据。

## C. 自我改进与实际使用

至少有一项 Harness 改进源于本次真实历史轨迹，并具备以下证据：

1. 指向旧版实际遇到的问题或重复开销。
2. 保存父版本、候选改动及提出改动的理由。
3. 后续独立进程或会话明确加载该候选，完成一个新的同类任务；轨迹能证明相关能力被实际使用。
4. 对改动前后执行相同研究工作负载，比较完成质量、模型调用、可获得的 token、耗时或恢复开销。至少有一项预先声明的过程指标改善，已有能力无回退；对计时等易受噪声影响的指标重复比较并报告差异。

无法测得真实费用时记为未知，使用调用次数或 token 等可测量指标。修改说明文字本身不足以通过此项，需要后续使用与对比结果。

## D. 无人交互与恢复

启动后从目标执行到验收不需要人工逐动作确认、提供下一轮任务或手动加载候选。目标拆分、失败分析、候选选择和必要的上下文交接在运行中自行完成。

至少在一次实际遇到或受控构造的失败中，正确识别错误、保留已有产物并继续完成任务，例如无效输入、缺失文件、失败候选或中断后恢复。保留失败证据，避免重复计入同一作业。不得关闭错误检查或伪造成功结果。

能够从保存的通过版本重新执行，并给出可恢复状态。对不可恢复的认证、网络或资源阻塞保存具体报告，标记本轮未完成。

## E. 版本、轨迹与交接

- A3、Harness 和被修改的第三方源码均可定位到基线与候选 Git 对象；未提交改动保留完整补丁。跨仓库版本组合一并记录。
- 候选记录父版本、所用版本、验证结果与保留/拒绝决定；失败节点不覆盖通过节点。允许串行分叉与回退。
- 各进程或会话的模型消息、工具调用、执行结果与结束状态落盘；记录实际调用数及可获得的用量。独立保存实验原始报告和失败日志。
- 最终摘要说明通过项、仍存在的问题、保留版本、后续启动方式，以及如何从证据复核研究和自我改进。检查目标与验收副本的摘要未改变。

复核时从保存版本重跑 A3 基础回归，重放一个研究任务，核对基线/候选的协议与逐回合数量，再检查新 Harness 的实际调用记录。自动检查通过后仍保留这些材料供事后审查。
