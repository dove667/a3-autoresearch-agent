# 开发路线

当前系统由研究 Agent 自主推进 Policy、数据采集、训练、评估和结果分析。人类与 Agent 依据原始执行轨迹维护 Harness，包括工具、上下文、记忆、skills、调度和恢复。

Harness 在本地原生进程运行；Host 保管认证并管理发布与身份；远程 Controller 统一管理作业、共享 GPU 与产物。维护发布继续使用同一研究工作区。新任务显式提供目标、验收与协议，不采用历史阶段编号。

后续优化优先依据真实轨迹：减少工具参数错误、无效检索、重复提交和无效模型等待，检查摘要是否完整、经验是否影响行动，并衡量端到端研究效率。功能回归、真实基础设施验证和科学实验结果分别记录。

历史阶段设计和验收条件保存在 `docs/plans/`、`docs/reviews/` 与 [archive/](../archive/README.md)。当前能力与操作入口见[文档导航](README.md)。
