# 第二阶段：完整网格下的 Policy 与 Harness 联合优化方案

目标、评估协议与独立阶段 Prompt 已维护，阶段输入选择已实现。离线依赖与只读大文件交接已受控验证；真实学习型 Policy 的训练和评测由 Agent 完成；并发、可选作业超时、只读资产挂载与跨身份合计存储监测已实现；尚未启动正式第二阶段实验；本方案不代写 Agent 的专项 Harness。

## 1. 本轮要得到什么

从用户明确选定的第一阶段保留版本开始，Agent 自主选择学习型 Policy、数据和训练/部署方法，用完整网格优化任务成绩；同时根据自己的轨迹优化 Harness。第一阶段验证“能组织闭环”，第二阶段要测量实际收益、代价及不确定性。

默认采用同一个 Policy 快照跑 2×5/2×10 × basic/medium/advanced，六格每格 20 回合；沿用 A3 网格程序，2×5 每回合最多 500 控制步，2×10 每回合最多 3200 控制步，均为 20 Hz。以六格归一化数量均值 G 为主选择指标，保留逐格结果和完整 success；Harness 另报同质量任务下的 token 与时间，不混成一个任意总分。

A3 README/工作流给出了六格、每格数量成绩与默认控制预算；六格等权归一化、开发/最终测试划分、配对统计与 Harness 比较，是本次提出的具体实验设计。任务真实目标仍是完整装盒；短指令数量评测不验证四次抓取计划服从性。

## 3. Agent 的两条优化循环

### Policy

读取可用模型和数据，选择可运行起点，先完成环境小样本检查，再建立 P0 开发集六格基线。可直接使用已有微调权重；选择基座训练时先审计数据，再短训练确认链路，随后开展有依据的完整训练。

之后自行从失败场景和记忆提出假设，选择模型、数据或部署改动，完成配对比较并决定保留/拒绝。低成本筛选允许使用较小预算，正式保留比较必须回到完整开发协议。选择模型或训练方法的工作由 Agent 做，人类不预写专项训练/搜索实现。

最终选定方案后，与 P0 在独立最终测试集比较，保存可复跑 Policy、完整分数和局限。不要求只训练 2×5；使用 2×10 数据或多任务训练如实记录，纯 2×5 训练才将 2×10 称为迁移测试。

### Harness

从真实轨迹定位问题，自定候选与测试清单，实际执行候选，在至少三个匹配的 auto research 工作负载上比较。质量保持后评估 token、调用、等待和恢复差异。

沿用现有单候选流程：当前主 Agent 保持决定权；普通 worker 验证局部能力，完整候选通过试运行才接任。Policy 与 Harness 版本分别记录，避免把模型训练变化归因为 Harness 收益。每个正式实验假设在执行前写入 Agent 自己的记忆，保存选择条件；完成后关联结果和决定。新会话、接任和新实验前检索相关先例及在途任务，减少遗忘和重复。记忆实现由 Agent 自行生长，人类不代写；具体规则见第二阶段 protocol.md。

## 4. 已实现的阶段输入选择

launch.py 与 InputVersions 已支持显式阶段选择，默认第一阶段。`--phase phase-two --run-harness <明确选定的阶段一run>` 选择第二阶段输入；执行前仍须完成下列环境、预算和保留 Harness 适配检查。

新 run 的 startup/input-manifest 保存 phase、来源 retained 版本及完整输入副本。第二阶段把 goal/acceptance 映射为该阶段文件，加载 protocol 与本阶段完整 Prompt。Host 的固定接口说明共用，不包含另一阶段的目标协议。主 Agent 和接任候选始终拿到同一版本的核心输入，普通 worker 不统一附加主任务。

resume 默认从原 run 元数据确定阶段，在该阶段内按现有版本机制加载当前输入；不得因默认参数把第二阶段恢复成第一阶段，也不得靠 resume 将已完成第一阶段改成第二阶段。跨阶段用新 run，保留来源关系。运行中更新需现有预览、警告与授权确认，更新协议后不混合统计旧结果。

阶段二新 run 使用保留 Harness 代码与持久记忆，但初始化新的模型上下文。当前支持 JSON 消息列表 checkpoint：Host 复制原快照，在副本中仅将消息列表替换为本轮目标；原始 checkpoint 与记忆不改。未知格式会明确拒绝，留给 Harness 提供适配入口。--resume-from 仍完整恢复同轮上下文。

## 5. 人类提前准备的基础设施

| 启动前检查 | 要确认的能力 |
| --- | --- |
| 阶段输入隔离 | 默认第一阶段不变；显式第二阶段；跨阶段新 run；resume 不串阶段 |
| 训练镜像 | A3/LeRobot 训练依赖、CUDA 前后向、数据解码、三相机及对应模型接口可用 |
| 模型与数据存储 | 预训练资产由人类提前准备到授权持久目录；候选输出独立；共享缓存按授权只读，凭据留在 Host |
| 大文件通道 | 权重/数据通过受控持久路径、摘要、流式或分块通道访问，不塞入 20 MiB JSON；恢复后访问权限可延续 |
| 长作业控制 | Controller 超时可配置，0 表示不限时；并发与存储由 Host 设置，内存配置与训练 checkpoint 保存仍需验证 |
| 预算与收尾 | 总 GPU 小时、语言模型 token/费用上限、下载/产物磁盘配额、单作业时限和收尾预留；明确有限额度或不限；存储当前采用提交前检查与 watcher 监测，正式训练还需验证保存与恢复 |
| 冷启动成果接续 | 已实现新上下文启动，源码、持久记忆和不可变原 checkpoint 可重复复用；真实学习型 Policy 执行仍待验 |

预算由部署方明确配置，可分别设置额度或显式不限。费用不限时仍记录可获得的 token 与费用。Agent 在预算内自由安排实验，不设人为总代数；Host 只做固定计量、限额与资源控制，不根据成绩重派任务。优先串行使用分配资源，当前不推进图式 worker 实验或大规模并发。

## 当前启动准备状态

阶段输入与新上下文、资源分配和只读资产访问已具备。进一步的模型依赖预检发现并修复了数字 UID 缺少用户名导致 PyTorch 编译缓存初始化失败的问题；模型缓存单独提供，作业不下载 backbone 或 tokenizer。预训练基座的任务适配、数据采集、学习型 Policy 的真实训练和闭环评测由 SWE Agent 完成。现有基础设施检查不计为 Policy 已运行或已经取得收益。

### 已实现的跨代大文件入口

可写输出仍按 worker 隔离。新增 Host 控制的 exports 将 Agent 明确选择的稳定文件或目录封存为带 SHA256 的只读快照，异步复制不占 GPU。主 Agent 在创建普通 worker 或接任候选时显式交接引用；后继远程作业通过 input_exports 只读使用。worker 也可把结果明确交付给当前主 Agent。未授权、未完成和越界引用拒绝执行。

Agent 可在 continuation.json 声明 remote_exports，Host 机械验证和保存；后续显式选择该 run 时自动重新授权。源码与记忆仍按原保留流程管理，Host 不选择 Policy、不设计记忆。快照计入来源 run 新增存储，后续只读引用不复制；清理前核对所有引用。

固定基础设施回归 219 项通过；实际执行端用 34 MiB 二进制文件验证了只读挂载、跨身份拒绝、源文件变动不影响快照、活动消费者保护及退出后的撤权/删除。独立代码审查与文档校验通过；未启动正式 RSI。
