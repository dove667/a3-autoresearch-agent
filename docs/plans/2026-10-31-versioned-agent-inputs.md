# Agent 输入版本与显式热加载

目标：启动和恢复均加载当前源码中的目标、验收、Prompt 与执行说明；保存输入版本和内容，不重写模型上下文或生成的 Harness。运行中的更新由操作者预览并确认。

- [x] 为 Agent 输入添加独立的语义版本；实现版本清单、历史副本与当前输入发布。
- [x] 启动和恢复接入当前输入，保留原 startup 与 checkpoint；模型请求和结束结果记录输入版本。
- [x] 添加仅操作者可用的热加载入口和 CLI，确认绑定预览内容，拒绝未确认或过期确认。
- [x] 同步 Agent 协议、开发文档和本地 AGENTS.md，明确版本递增与更新边界。
- [x] 回归测试、无模型受控验证与独立审查；本批不自动提交，原运行的恢复验证按既有明确授权执行。

关键检查：同版本内容变化、启动失败时保留旧副本、恢复不丢上下文、运行中旧请求与新请求各自记录版本、私有输入挂载同步更新、Agent 不能自行更新部署方目标、最终验收按生效版本读取。

验证：150 项单元测试通过，Ruff 与 diff 检查通过；无模型、无 GPU 的实际 Docker/HTTP/CLI 检查确认预览不激活、确认后同一容器读取新版私有挂载、普通挂载一致及原快照保留。独立审查发现的多文件发布窗口、回滚标记、YAML 校验及结束核验边界已修复。
