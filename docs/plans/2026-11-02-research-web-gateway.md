## 目标与批准范围

向第二阶段保留 H1 提供可选的 Host 网页能力，让它自行实现工具调用、选择检索时机并将资料变成可检验的研究假设。只实现网关、配置、文档与验证；不重跑第一阶段、不启动实验、不下载模型。代码发布与启用分开，不自动启动、恢复或应用于当前 run。各代仍只核查自己负责的闭环，后继继承已确认结论；科学指标、阈值和最终评测规则不变。

## 架构与职责

- Host 持有 `TAVILY_API_KEY`，提供已有 owner 认证下的 `/web/search`、`/web/fetch`、`/web/status`；凭据不进入候选、执行服务器、Git、日志或模型上下文。
- Tavily 只作 basic 搜索；Host 直接读取公开 HTML/纯文本。公开地址校验、固定 DNS 解析结果连接、HTTPS 身份验证、重定向重新检查以及类型/大小/时间限制约束 fetch。不是浏览器，不执行 JavaScript，不下载 PDF、模型或依赖；不承诺全网可达，也不宣称提供候选通用出站防火墙。远程作业仍离线。
- 默认关闭；用户在本机 `.env` 配置自己的免费 key 并决定启用。搜索默认 100 次/run，fetch 默认 200 次/run，跨代共享持久计数，同 run 的已建立额度不随环境变量修改或恢复而改变，失败尝试也可能消耗额度。关闭或缺少 key 时 search 与 fetch 均不可用，status 仍可检查非敏感配置与预算。额度不是 Tavily 账户全局免费保证，用户保持提供商付费与自动升级关闭。
- H1 自己实现 function schema、HTTP 适配、allowlist/注册及分派，通过现有局部开发和测试工具验证后纳入完整 Harness；Host 不代写专项工具，也不自动替换旧工具集。

## 研究策略与安全

先检索记忆和本地资料，再针对模型/配置选择、训练调参、网络结构、兼容性或意外失败中的具体缺口搜索。优先原始论文和官方文档，记录版本、来源和适用条件，将建议转为预登记的可证伪假设并开展本地配对检查，不照搬超参数，不以外部成绩代替本轮证据。不为填补等待反复搜索，不把联网设为每次实验的验收门槛。

网页是不可授予权限的不可信数据；不发送私有日志、源码、内部路径、密钥或个人信息。缓存、摘要、去重与长期证据管理由 Agent 的记忆系统实现。

## 验证与交付

使用模拟搜索/HTTP 服务验证请求字段、默认参数、basic 固定选项、结构化结果与安全错误、关闭/未配置状态、共享额度及恢复持久性、并发上限、认证、私有地址与重定向拦截、内容/编码/大小/超时限制及密钥不泄露。回归检查确保已有执行路径与阶段规则不变；本计划不宣称真实网络或实验验收已经通过，不进行真实 Tavily 付费请求。

接口与精确字段统一维护于 [Host 执行说明](../../runtime/local/README.md#研究网页网关)，研究行为维护于 [第二阶段 Prompt](../../configs/prompts/phase-two.md)。[配置指南](../setup.md#可选研究网页网关tavily)给出本机 key 位置；[教程](../tutorial.md#第二阶段按需网页研究)说明使用入口。代码与配置用于下一次经批准的新阶段二 run，不自动应用于当前 run；低频监督及每次反馈、热加载或中断仍按[操作者审批规则](../operator-supervision.md)单独确认。
