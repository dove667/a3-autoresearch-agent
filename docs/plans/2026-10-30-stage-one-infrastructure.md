## 取舍与验证

新身份复跑由 Host 注入新认证和冻结输入，原样加载 SWE 生成的代码；不修改其提示词或补写专项实现。候选版本与执行会话分别记录，同一个版本可多次启动。Host worktree 的 `source/` 子目录作为 Docker 工作区，共享 Git 数据不挂载进去。版本共享只随显式父子交接，兄弟实验互不可见；跨 Agent 调度与去重策略留给后续设计。

协议检查固定必填比较条件，并允许额外条件参与严格比较；缺少字段、失败或缺报告均给出未通过反馈，不替 Agent 宣称效果更好。记忆验收要求真实写入、跨会话检索、追溯来源、合理复用失败经验及遵守实验权限，不规定数据库、向量检索或索引实现。

测试重点为不可变 commit、分支来源、worktree 隔离、版本访问拒绝、新身份加载、协议缺失与差异、失败诊断与脱敏。只运行本项目小规模基础设施验证，不运行 A3 开发测试、GPU 实验或真实模型任务。
