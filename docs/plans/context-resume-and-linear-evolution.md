# Context resume 与线性 Harness 迭代

当前运行保持原样。开发与测试在独立工作区完成，不启动正式实验。

1. 恢复 mini 的原消息、工具结果、统计与冻结配置，拒绝已提交会话和结果不明确的工具调用；恢复不再通过历史材料提示词重建上下文。为生成后 Harness 定义显式 checkpoint 恢复接口，缺失时拒绝假恢复。同步教程与恢复边界，测试并单独提交。
2. 区分 evaluation session 与下一代 main session。一个主 Agent 发起同条件 H0/H1 测试并接收结果，自行选择保留或回退；选中 H1 后才交接给下一代主 Agent。Host 只落实角色、版本、单主与资源边界，不提出改动、不评判实验收益。专项 Harness 和记忆由 SWE 实现。
3. 测试消息恢复、重复动作拒绝、版本/角色与线性迭代约束，复核文档。禁止将新机制加载到当前运行。
