# 研究看板

本地只读网页，把最新一次 run、共享计划、长期记忆、技能库和运行记录分成六个页面。深色金色界面，导航切换页面，不需要手动刷新。

## 启动

```bash
uv run a3-research-dashboard
```

默认地址为 <http://127.0.0.1:8787>。常用参数：

```bash
uv run a3-research-dashboard --open       # 启动后打开浏览器
uv run a3-research-dashboard --port 8788  # 更换本地端口
```

看板只监听回环地址。停止服务使用 `Ctrl+C`。

## 页面

- **总览**：Agent 状态、当前研究重点、研究活动柱状图和四项概况。状态区分未启动、启动中、运行中、等待远程作业、等待事件、整理上下文、已阻塞、已暂停、已停止和异常中断。
- **研究计划**：长期方向、研究路线、待推进步骤和完成数。点击路线查看假设、实验、决策规则与结论。
- **结果复盘**：最近的路线决策和结论；点击展开完整结论与指标。
- **长期记忆**：按有效、已归档、已被替代筛选，可搜索；点击条目查看全文、标签和依据。
- **方法技能**：技能摘要与版本；点击查看完整正文和附件数量。
- **运行记录**：最近的作业与决策事件，以及模型、上下文和作业概况。

每页高度跟随窗口，内容多时只在页内滚动；通过左侧导航切换，不把全部板块堆成一张长页。

## 自动更新

页面每 5 秒请求一次 `/api/snapshot`，服务端每次重新读取当前文件，并返回 `Cache-Control: no-store`。因此：

- 计划修订、记忆写入、技能更新和作业状态变化会在下一次轮询时出现；
- 新 run 出现后，“最新运行（自动）”会自动切换；
- 在运行下拉框中选定旧 run 后会固定查看该 run，选择“最新运行（自动）”恢复跟随；
- 不需要重新启动服务或手动刷新页面。

## 数据来源

看板只读以下运行资料：

- `trajectories/latest-run.txt` 与 `trajectories/<run>/` 下的启动、Host、会话、监督、结果、作业与活动记录；
- 项目根 `plan/current.json`；
- 根 `memory/entries.jsonl`；
- 根 `skills/<id>/SKILL.md` 与 `assets/catalog-entry.json`。

它不读取或返回 Host 的认证令牌，不提供写接口，不修改 plan、memory、skills 或研究文件。普通页面请求失败时保留上一帧，并在顶部显示错误提示。
