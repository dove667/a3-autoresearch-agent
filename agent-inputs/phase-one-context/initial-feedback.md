# 本轮人工干预说明：启动 G

Version: 0.1.0

这是外部用户与助手为新 G 任务提供的初始反馈，不是运行中的热加载，也不是要求恢复已完成的 F run。

用户批准把“上下文管理”作为第一阶段新增任务 G。我们检查了 F 实际成果：它保存、恢复并逐次发送完整 messages，但没有运行中按预算触发的语义压缩。因此本轮从明确选定的 F ready 保留包继承已有能力，创建新 run，只补 G。源 F 包及历史记录不修改；A–F 的结论和限制按来源继承，不要求你重新验收。

本轮新上下文是新任务初始化，不代表 G 已经实现。请依据当前 goal、acceptance、phase-instructions 完成运行中摘要、原文回查、协议完整性及恢复检查。我们不指定压缩算法，也不会把外部说明当成通过结果。

此前 F 曾额外要求每次都完整复制最新主 Agent 的现场对话，导致不必要的阻塞。本轮不要求这样做：用明确固定的代表性状态验证同一最终实现能够压缩、回查和恢复即可。不要扩大为祖先对话重审或反复证明新主的全部历史传输。

项目已提供外部编写的 A3 研究 skill；若本轮输入附带它，按需阅读并保持来源，不必为了 G 重新研究/生成 skill，也不要把整个技能库默认加入工作上下文。机器人研究、训练和正式评测留待后续任务。本轮完成后保存可用成果并退出，不自动进入第二阶段。
