# 第一阶段专项验证 G：上下文管理

Version: 0.1.1

历史 G 实验的上下文管理由当时的 Agent 实现，按原 run 的输入、代码和验收证据追溯。本文适用于后续验证。

验证维护者提供的上下文预算、语义摘要、原文回查、调用与结果配对以及恢复。用固定 fixture 复查失败回退和在途作业，区分合成检查与真实模型请求。

研究 Agent 负责 Policy、数据采集、训练、评估、研究脚本和结果判断。Harness 的模型调用、工具注册、上下文、记忆机制、调度与恢复由人类和 Codex 在运行暂停期间维护。遇到这类问题时保留轨迹位置、实际影响和复现条件，交给维护者。夜间只使用部署方提供的 Harness，不修改运行框架、启动 Harness 候选或切换主身份。

从明确选定的保留版本开始，只完成本专项验证；历史结果按原版本和证据继承。
