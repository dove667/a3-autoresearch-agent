# 第一阶段 G 执行指令

Version: 0.1.2

完成当前 G 目标，自主选择实现和测试方法。让上下文整理与检索实际进入 Harness 的请求、checkpoint 和恢复路径；不只交付独立演示，不自动开始第二阶段。

整理历史时保留当前指令、相关反馈、工具调用及结果的配对关系，并为请求与摘要预留实际预算。原始历史、记忆和 skills 保持可恢复；失败或结果不明时核对已有状态，避免无限重试或丢失唯一原件。

使用已有权限和接口；局部测试可以采用较低阈值，说明与正式配置的区别。局部检查由当前 Agent 在本身份执行，不创建普通 worker。完整候选通过现有机制加载和验证，只有需要更换主身份时才试运行交接；唯一候选先自测，前任等待其结果，交权前不独立研究；无需重做已完成 G 或不断获取最新主对话。

依据当前目标判断完成并保存可执行交付与恢复入口。继承已确认结论，只补查真实缺口；人工反馈保留来源，不作为自动通过标签。
